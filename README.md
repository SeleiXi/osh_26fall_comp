# 页面替换算法实验

使用 Python 3（无第三方依赖）模拟 demand paging，比较 FIFO、OPT/MIN、LRU、Second Chance 和自设 WindowFreq。只在访问缺页时装入页面，不预取。OPT 利用未来访问序列作为离线理论下界，不能作为现场在线替换策略。

## 现场运行

```powershell
python page_replacement.py "现场给的文件.txt"
```

每行一个页号，按字符串区分（区分大小写；十六进制页号不需要转换）；行首尾空格和空行被忽略，其他多个字段报错。输入需为 UTF-8（可带 BOM）。程序输出每种算法在 5、10、20、50、100 个页框下的缺页次数及五个次数的算术平均值；初始页框为空，首次访问也计缺页。

```powershell
python page_replacement.py data/mm32.txt --window 200 --csv results/example.csv
python -m unittest -v
```

如果系统使用 `py` 启动 Python，可把上述命令中的 `python` 换成 `py`。窗口为正整数，默认 200。CSV 包含相同的数据。

## 自设算法：窗口频率 + 最近使用

记录最近 W 次访问中每个页号出现的次数，缺页且页框已满时，淘汰驻留页面中窗口内访问次数最少的；次数相同时淘汰最久未使用的页面。窗口统计包括已被淘汰的页面，能反映近期访问习惯。随后只装入当前访问的页面。窗口过短可能无法区分周期性访问，过长可能保留过时的访问趋势；淘汰时扫描全部页框，时间复杂度为每次缺页 O(页框数)，窗口与驻留页占用 O(W + 页框数) 空间。

## 数据与实验

`data/` 包含题目提供的四个 trace（`sort1.txt` 对应课件中的 qsort）及原始数据说明。`results/` 中各数据集 CSV 为默认窗口 200 下的完整结果，`window_sweep.csv` 为窗口 20、50、100、200、500 的参数实验。下表为五种页框数缺页次数的平均值：

| 数据集 | FIFO | OPT | LRU | Second Chance | WindowFreq (W=200) |
|---|---:|---:|---:|---:|---:|
| sort1 | 396.0 | 302.0 | 394.0 | 394.8 | 367.2 |
| lu | 37086.6 | 25293.8 | 36093.6 | 36143.0 | 30636.8 |
| mm16 | 6978.4 | 4188.2 | 6630.6 | 6642.4 | 5326.2 |
| mm32 | 57052.4 | 35455.2 | 54633.8 | 54703.4 | 40838.4 |

在这四条 trace 上，WindowFreq 的平均缺页次数均低于所比较的在线基线，但 OPT 仍更低。对于 mm32，W=20 的平均值为 54633.8，W=200 降至 40838.4，W=500 回升至 41064.8；窗口大小影响性能。默认值 200 是根据给定数据观察选定的，不能保证对现场未知 trace 最优。单个页框数下也不保证优于所有基线，完整数字见 CSV。

## WFM 补充实验

WFM 的窗口长度随页框数 F 调整为 max(64, 4F)，淘汰窗口中频率最低的驻留页；频率相同时淘汰最近使用的页。统计窗口在处理当前访问之前计算，包含所有历史访问，不限于驻留页。`results/wfm.csv` 记录各页框数结果，可用 `python generate_wfm_results.py` 重现；主程序也会输出 WFM。

| 数据集 | WFM 平均缺页 | WindowFreq 平均缺页 | LRU 平均缺页 |
|---|---:|---:|---:|
| sort1 | 363.0 | 367.2 | 394.0 |
| lu | 28536.8 | 30636.8 | 36093.6 |
| mm16 | 4738.8 | 5326.2 | 6630.6 |
| mm32 | 38939.8 | 40838.4 | 54633.8 |

在 1 到 7 循环 100 次、5 个页框的例子中，WFM 缺页 285 次，LRU 缺页 700 次。这些结果同时改变了窗口长度和平局规则，因此不能单独归因于 MRU；WFM 在部分单个页框数下也会更差。
