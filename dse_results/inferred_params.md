# 参数范围

目标：四个数据集、五种页框数上在线算法缺页次数与 OPT 的比值的算术平均，越小越好。所有页面等权，所有 trace 等权。OPT 仅用于离线评价；淘汰决策不能访问未来。基准为 WFM：窗口 max(64,4F)，频率并列时淘汰 MRU。

| 参数 | 范围 | 理由 |
|---|---|---|
| 窗口下限 | 32、64、128、256 | 覆盖不同访问周期 |
| 窗口与 F 比例 | 2、4、8、16 | 适应工作集规模 |
| 并列规则 | MRU、LRU | 测试扫描和局部性 |
| 预测方法 | 历史转移预测、窗口频率 | 测试在线推测未来复用 |

作为内部实验的参数在四条给定 trace 上选择，独立合成序列用于排查严重退化，不构成对现场分布的性能保证。
